# Portfolio — Samuel Landry Woulle Ndedy

Portfolio web professionnel conçu avec **React**, **Vite**, **Tailwind CSS**, **Framer Motion** et **Lucide React**.

## Démarrage local

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
npm run preview
```

## Personnalisation rapide

- **Données (projets, expériences, formations, liens)** : `src/data/portfolioData.js`
- **CV PDF** : placer votre fichier dans `public/cv-samuel-woulle-ndedy.pdf`
- **Captures d'écran des projets** : placer vos images dans `public/projects/` (`choozz.png`, `sonoritiz.png`, `jobconnect.png`, `reseau-social.png`)
